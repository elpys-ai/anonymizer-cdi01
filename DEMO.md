# Сценарий защиты — 3–5 минут

## 1. Задача и границы

«Я доработала учебный Анонимайзер курса Zerocoder. Он помогает убрать распознаваемые телефоны, почту и номера карт из учебного текста. Исходное приложение готовое; мой вклад — исправления, проверки и подготовка к передаче. Приложение локальное и не обещает полной анонимизации всех видов персональных данных».

## 2. Запуск по README

Открыть терминал в папке проекта. Проверить Tkinter командой из README, выполнить `python3 anonymizer.py`. Показать окно.

## 3. Основной сценарий

Вставить полный primery/pokupatel.txt, нажать «Скрыть данные».
Показать 2 маркера [телефон], 1 [почта] и счётчики.
Дополнительно показать primery/kvartira.txt: карта и телефон скрыты.

## 4. Пограничный случай

Очистить верхнее поле, нажать кнопку. Показать сообщение о пустом поле и очищенный результат. Затем вставить обычную строку без данных — текст не меняется.

## 5. Улучшение до → после

Показать evidence/whitespace-improvement.patch. До исправления `.strip()` удалял пробелы/переносы по краям. После разделения чтения и проверки пустоты они сохраняются.
Запустить `python3 tests/test_anonymizer.py`: ожидается 14 тестов и OK.
Не выдавать исторические снимки CDk01 за запись этой защиты.

Дополнительное улучшение CDi01: показать читаемую тёмную надпись кнопки на macOS. Раньше белая надпись терялась на светлой системной кнопке; правило выбора цвета отражено в evidence/macos-button-contrast.patch.

## 6. Передача и ограничения

Открыть PROJECT_BRIEF.md, README.md и ACCEPTANCE.md. Показать папку/архив.
Объяснить: данные между запусками не сохраняются; не проверены все международные форматы, длительная нагрузка и все платформы.
Публичный репозиторий: https://github.com/elpys-ai/anonymizer-cdi01. Скачать исходники можно через Code → Download ZIP. Проект запускается локально; веб-демо для Tkinter не предусмотрено.
