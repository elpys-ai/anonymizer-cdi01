# Паспорт проекта «Анонимайзер»

Учебная доработка готового проекта CDk01 курса Zerocoder; финальная сборка CDi01.
Авторство исходного приложения студии «Форма» не присваивается.

- Пользователь: автор или технический специалист онлайн-школы, готовящий учебные примеры переписки.
- Проблема: перед показом текста приходится вручную искать телефоны, почту и номера карт.
- Вход: текст, вставленный человеком в окно. Для демонстрации используются только вымышленные примеры из primery/.
- Действие: заменить распознанные данные маркерами [телефон], [почта], [карта] и посчитать замены.
- Результат: обработанный текст в нижнем поле; окружающий текст, пробелы и переносы сохранены.
- Основной сценарий: запустить окно, вставить pokupatel.txt, нажать «Скрыть данные», получить два [телефон] и один [почта] и соответствующие счётчики.

## Первая версия

Локальное окно Tkinter; скрытие российских телефонов, почты по упрощённому шаблону и последовательностей карт из 13–19 цифр с одиночными пробелами/дефисами; счётчики; сообщение при пустом вводе; сохранение окружающего текста.

## Отложено

Импорт документов, пакетная обработка, сервер, учётные записи, синхронизация, сохранение истории и автоматическая проверка того, что в тексте скрыты абсолютно все личные сведения.

## Критерии готовности

1. Пример покупателя: два телефона и одна почта скрыты.
2. Пример квартиры: скрыты карта и телефон, прочие слова и числа сохранены.
3. Текст без распознанных данных возвращается без изменений.
4. Пустое/пробельное поле даёт понятное сообщение и очищает предыдущий результат.
5. Тесты длины карты 13/19 принимаются, 12/20 не считаются картой; учитываются варианты регистра почты.
6. Краевые пробелы и переносы сохраняются для непустого текста.
7. Перезапуск создаёт пустую рабочую сессию: сохранение данных не обещается.

## Ограничения и зависимости

Python 3 с Tkinter и графическая среда. Проверено на macOS с Python 3.15.2 и Tk 9.1. Регулярные выражения упрощённые; приложение не распознаёт ФИО, адреса, документы и все международные форматы. Это учебный инструмент, а не гарантия полной анонимизации. Рабочий сценарий не требует сетевых сервисов.
